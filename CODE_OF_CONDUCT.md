# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep criticism about the work and not the person, and
no harassment of any kind. This applies to all project spaces: issues, pull requests, discussions
and any channel run under the SealedRun name.

Report unacceptable behaviour to **info@sealedrun.com**. Reports are handled confidentially.
Maintainers may remove, edit or reject contributions and may ban contributors, temporarily or
permanently, for behaviour that breaks this code.
